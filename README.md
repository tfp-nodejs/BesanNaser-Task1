# Fetch API Tasks

This repository contains three tasks using the **Fetch API** in JavaScript with **Async/Await** syntax.

## Tasks

### Task 1: Fetch a Single Post
- Send a GET request using the Fetch API.
- Fetch a single post with ID `1`.
- API Endpoint:
  `https://jsonplaceholder.typicode.com/posts/1`

### Task 2: Fetch All Posts
- Modify the previous request to fetch all posts.
- Remove the post ID (`1`) from the API endpoint.
- API Endpoint:
  `https://jsonplaceholder.typicode.com/posts`

### Task 3: Filter Posts by Title Length
- Fetch all posts from the API.
- Use the `filter()` method to select posts whose title length is less than 25 characters.
- Print only the filtered posts to the console.

## Technologies Used
- JavaScript
- Fetch API
- Async/Await
- Promises
- Array Filter Method

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the following command:

```bash
node index.js
```
